# Content Creation Checklist

## 1. Pre-Production
- [ ] Brainstorm idea and check viability (search volume/trends).
- [ ] Complete `research_template.md`.
- [ ] Draft script using `script_template.md`.
- [ ] Review and finalize script.
- [ ] Prepare assets (B-roll, images, music).
- [ ] Set up recording equipment (camera, mic, lighting).

## 2. Production
- [ ] Record A-roll (main footage).
- [ ] Record/gather B-roll.
- [ ] Record voiceovers (if applicable).

## 3. Post-Production
- [ ] Organize files.
- [ ] Rough cut (assemble A-roll).
- [ ] Add B-roll, graphics, and text.
- [ ] Color correction and audio mixing.
- [ ] Add music and sound effects.
- [ ] Final review.
- [ ] Export video.

## 4. Publishing
- [ ] Create thumbnail.
- [ ] Write title and description (use prompts if needed).
- [ ] Add tags and end screens.
- [ ] Upload and schedule/publish.
- [ ] Promote on other channels.
